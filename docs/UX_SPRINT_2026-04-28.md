## Priority 1 — Risk-adjusted Leaderboard

**Why:** Highest impact lever for trust and decision-making. Today's
ghost scorecard work directly supports this; today's halt-gate work
makes per-agent gating possible.

**Add to each Leaderboard row:**

- Sharpe ratio (rolling 30d / 90d / all-time)
- Sortino ratio (downside-only volatility)
- Max drawdown
- Sample size flag: "<30 trades — too few" / "30-100 — emerging" /
  ">100 — meaningful"
- Calibration column: "When agent says 0.85 confidence, realized
  hit rate was X%" (uses ghost_predictions table)
- Per-agent equity curve sparkline
- Filter: "Only crew with Sharpe > 1 over 90 days"

**Endpoint to extend:** `/api/agents/scoreboard` already returns
trade_count, win_rate, profit_factor. Add the new fields server-side,
update Leaderboard component to render them.

**Calibration data source:** Already exists at signals.db
ghost_predictions table. Today's diagnostic confirmed: chekov
(PF 0.86), tractor-beam (PF 0.63), navigator (PF 0.20) — all <1
on PF, all with avg confidence 83-88%. That's the calibration gap
the panel will surface.

## Priority 2 — "Today's Read" Strip + Collapsible Cards

**Why:** Daily-use friction. Glanced at the dashboard 20+ times today
and confirmed: nested scroll regions trap user input, Bridge Status
panel is a 14+ row firehose.

**Implementation:**

1. **Top strip (above the fold, sticky):**
   - Regime: BULL / CAUTIOUS / BEAR / CRISIS
   - Consensus: "NO CONVERGENCE" / "3 AGREE: <ticker>"
   - Action: 1-line plain-English ("Stay in cash" / "Watch <ticker>
     for entry")
   - System health: green/yellow/red dot

2. **Bridge Status modules → collapsible cards:**
   - Riker XO, Consensus, Earnings, Congress, Portfolio, Metals,
     Sentiment, Recovery, Gamma, Wheel, Sectors, Macro, VIX
   - Each card collapses to header-only by default
   - Click to expand for detail
   - Per-user collapsed/expanded state persisted

3. **Flatten nested scroll:**
   - Single page scroll, sticky top strip
   - Fleet Activity panel becomes a section, not a nested scroll
     region

**File:** `dashboard/static/index.html` + `dashboard/frontend/dist/`

## Priority 3 — Plain Mode Toggle

**Why:** Bonnie and Dad don't speak Star Trek. Multi-user system
already supports per-user preferences (memory #14).

**Implementation:**

- Settings toggle: "Plain Mode" (per-user, persisted)
- When enabled, swap labels:
  - "Riker XO" → "End-of-day synthesis"
  - "Lt. Cmdr. Spock" → "Logic / quant signals"
  - "Lt. Cmdr. Uhura" → "Sentiment & news"
  - "Counselor Troi" → "Options strategist"
  - "Dr. McCoy" → "Finance LLM (Plutus)"
  - "Stardate 2731.39" → "April 25, 2026"
- Default: Trek mode for Sniff (admin)
- Default: Plain mode for Bonnie (observer), Dad (charts)
- Toggle visible in user settings, not buried
