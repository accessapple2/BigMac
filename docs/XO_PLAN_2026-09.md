(`data/reports/relay/relay_2026-09-09_mccoy-8b-vs-30b-bakeoff.md`). That

## Phase 0 — Baseline (starts 2026-09-09, read-only)

**What:** a daily script, no writes to `trader.db`, that:
1. Pulls McCoy's (`ollama-plutus`) BUY signals for the trading day.
2. Dedupes by symbol (highest-confidence instance per symbol), ranks by
   confidence, takes the top 20.
3. Computes each one's forward return from signal timestamp to that day's
   13:00 MST close (Alpaca IEX 1-min bars — same methodology as the
   2026-09-09 bakeoff).
4. Compares the equal-weighted top-20 average return to SPY's open-to-close
   return the same day.
5. Writes a dated report file under `data/reports/mccoy_baseline/` (JSON +
   printed summary) — no DB writes, no trades, no config changes.

**Why:** every later phase (structure changes, McCoy Rank, hedging) needs a
"compared to what" — this is that number, running before anything else
changes so later deltas have a pre-change baseline to compare against.

**Cadence:** daily after close (cron, ~13:10 MST — after the 13:00 close so
the day's bars are final). First run: today, 2026-09-09, manually.

**Acceptance:** none — this phase doesn't gate on a number, it *produces*
the numbers everything else gates on. Runs indefinitely alongside every
later phase.

## Phase 1 — Structure (one change per day, each with an acceptance check)

Each sub-phase ships alone, runs at least one full trading day, and is
checked against its acceptance criterion before the next one starts. No
sub-phase touches sizing or execution live until its own day has run clean.

  what's happening now: **pending is 4,023 as of tonight, not the

  1. **Two sessions of post-1.2 backlog readings** (not before — Phase

  2. **Age-ordered / priority lane in `engine/events_bus_consumer.py`.**
     Today's `consume_pending_signals()` (verified in code) does
     newest-first for the bulk of each batch plus a fixed reserve of the
     `_OLDEST_RESERVE = min(2, max_batch)` oldest rows — a fixed head-count
     reserve, not an age- or priority-aware lane. Replace with a real lane
     so freshness actually drives consumption order, not just a small
     constant carve-out.
  3. **Drain plan for the existing backlog** (2,894 at last count, 4,023
     now — use the live count when this session actually runs, not

     (a source with `halt_mode != 'active'` can never execute regardless

     archived once), then drain what's left through the new lane. Marking

  4. **Sentinel growth-rate check.** `scripts/hm_ops_sentinel.py::check_signals_v2_queue()`

     `pending > QUEUE_PENDING_WARN` and `oldest_age_hours >

     Pushover redesign's tier scheme) even when age stays inside ceiling.

  **Coordination question — DECIDED 2026-09-11 (Admiral). Spec below,
  NOT built yet.** `learning_engine.apply_learning()`'s `confidence_modifier`
  and `engine.calibration_map.get_calibrated_confidence()` are two
  independent confidence-adjustment mechanisms that don't know about each
  other today. **Decision: one adjustment, one owner, evidence-based.
  `learning_engine` keeps owning the actual gate/block/multiply
  enforcement (`apply_learning()` stays the single call site every
  decision passes through); `calibration_map` becomes its evidence
  source, replacing the LLM-guessed weekly number.** Concretely:

     player, every row — see the 2026-09-11 pipeline-trace relay doc for
     why: `weekly_tuning_crew.py` prompts an LLM for it and the value
     never lands) gets populated by `calibration_map` instead.** A daily
     job (natural home: alongside `_flag_no_trade_active_players()`,

## Phase 4 — Leakage & bias diagnostics

- **Ticker-masking leakage check:** re-run a Phase 2 arm with the ticker
  symbol redacted/replaced from the prompt (company description only) to
  test whether the score is actually reading the setup or just pattern-
  matching on which names it "likes." A large score delta between masked
  and unmasked runs on the same setup is a leakage signal.
- **Reverse-McCoy:** invert McCoy's own scored direction and track it as a
  **diagnostic only** — never a fleet seat, never executed. Purely answers
  "does McCoy carry information in either direction, or none at all" as a
  sanity check on the whole program.
